# Kings React App

This is a simple React project scaffolded with Webpack and Babel (no Vite).

## Getting Started

1. Install dependencies:
   ```
npm install
   ```
2. Start the development server:
   ```
npm start
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view the app.

## Build for Production

```
npm run build
```

---

This project uses:
- React
- Webpack
- Babel
